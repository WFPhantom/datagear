# DataGear

DataGear is a lightweight mod that allows you to modify any block or item's modifiers with data. While originally meant for armor, tools and weapons, you're more than welcome to add armor and a `head` slot to a stone block and wear that around :P

Players -> If you see this mod it is likely a mod is using it as a library, or a modpack creator is using it to modify items, dont mind it :)
